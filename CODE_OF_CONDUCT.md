# Community code of conduct

MewLink welcomes respectful participation regardless of identity, experience,
or background. Harassment, threats, doxxing, stalking, sexualized abuse, and
using the project to enable coercive monitoring are not acceptable.

Project spaces should stay constructive and privacy-conscious. Maintainers may
edit, remove, or reject contributions and participation that violate these
standards. Until a private conduct address is configured, report sensitive
conduct concerns through GitHub's private reporting tools rather than a public
issue.
