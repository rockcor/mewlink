# 当前完成度与下一步

## 已实现

- 自动贴靠右下角的一对完整透明抠图桌宠；两个不同造型同时代表自己和 TA，悬停操作、单击 TA 宠物拥抱、双击喝水，以及七种活动贴图动画。
- 拥抱与三种个性化水杯使用独立互动动作，不再使用水滴图标；杯型会随加密事件和回放传递。
- `idle/lock` 与前台应用检测抽象：macOS 已接入真实会话、前台应用和键盘/指针事件时序；Windows 已实现前台进程与输入节奏适配器。
- 键盘、鼠标和触控板活动驱动本机宠物动作；不读取输入内容、指针坐标、窗口标题或屏幕像素。
- 状态贴图缩至 768×512，移除三张闲置大图，加密库按需加载，采样随 active/idle/rest 自适应降频。
- 写代码与开会改为专注严肃表情；默认动画节奏放慢，并提供舒缓、自然、活泼三档速度。
- 悬停菜单新增设置页：自动检查更新、手动时区、动画速度与反馈分享；所有偏好保存在本机。
- 活动分类纯函数与防抖轮询控制器。
- 版本化事件和 XChaCha20-Poly1305 加密信封原型。
- IndexedDB 本地事件存储。
- 情侣互动本地 loopback mock，支持静音、专注缓存及频率限制。
- 状态/互动合并后的 replay 时间线和快速回放 UI。
- 回放按 UTC 排序，并使用双方事件时刻的本地 UTC 偏移显示双时钟；不共享城市或时区名称。

## 尚未完成（不能用于生产）

- 仍需在真实 Windows 机器上验证锁屏、安全桌面、前台进程读取、输入节奏和计时回绕，并补充 macOS 锁屏/解锁端到端测试。
- 浏览器内的视频或网页会议仍只能安全地归为 `browsing`；除非未来由用户显式授权更强信号，否则不会读取标签页标题或 URL。
- 密钥仍是每次会话生成的 demo key；未进 Keychain/Credential Manager，未实现设备绑定、X3DH/Double Ratchet、撤销和多设备。
- IndexedDB 是原型存储，未迁移至 Rust SQLite/SQLCipher。
- 没有真实后端、推送、配对或跨设备网络收发；当前 TA 宠物由本地 loopback 与回放事件驱动。
- DP 只有设计，尚未实现/审计；默认不发布任何聚合。
- 缺少安装包签名、无障碍/权限 UX、安全审计、流量填充及完整可访问性。
- 更新功能目前完成版本源检查和新版本提醒；安装包签名发布后再接入安全的后台下载与原位安装。
