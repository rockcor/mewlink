# 当前完成度与下一步

- 自动贴靠右下角的透明抠图桌宠；悬停操作、单击拥抱、双击喝水，以及七种活动贴图动画。
- `idle/lock` 检测抽象：浏览器 mock + Tauri command 适配器；macOS 真实会话信号已验证，Windows 原生 API 已通过目标平台编译检查。
- 活动分类纯函数与防抖轮询控制器。
- 版本化事件和 XChaCha20-Poly1305 加密信封原型。
- IndexedDB 本地事件存储。
- 情侣互动本地 loopback mock，支持静音、专注缓存及频率限制。
- 状态/互动合并后的 replay 时间线和快速回放 UI。
