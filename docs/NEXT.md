# 当前完成度与下一步

## 已实现

- 自动贴靠右下角的一对透明桌宠；两只宠物可分别右键缩放，工作、会议、休闲、idle 与休息保持统一视觉尺寸。
- 单击 TA 宠物拥抱、双击喝水及杯型/被子事件会加密收发；商城范围只含水杯和被子。
- `idle/lock` 与前台应用检测抽象：macOS 已接入真实会话、前台应用和键盘/指针事件时序；Windows 已实现前台进程与输入节奏适配器。
- 键盘、鼠标和触控板事件按真实频率驱动：左手只负责键盘，右手只负责鼠标，可同时动作；身体、脸与设备像素不变。
- 状态贴图缩至 768×512，移除三张闲置大图，加密库按需加载，采样随 active/idle/rest 自适应降频。
- 写代码与开会改为专注严肃表情；默认动画节奏放慢，并提供舒缓、自然、活泼三档速度。
- 悬停菜单新增设置页：时差重放开关、配对后的双方时差自动识别、自动检查更新、手动时区、动画速度与反馈分享；所有偏好保存在本机。
- 活动分类纯函数与防抖轮询控制器。
- 版本化事件和 XChaCha20-Poly1305 加密信封原型。
- IndexedDB 本地事件存储。
- 两台设备可通过 24 小时有效的 8 位配对码绑定，核对 6 位号码后，经只保存不透明加密数据的邮箱中继双向发送拥抱与喝水；已覆盖离线领取、防重复和双向解密测试。
- 状态/互动合并后的 replay 时间线和快速回放 UI。
- 回放按 UTC 排序，并使用双方事件时刻的本地 UTC 偏移显示双时钟；不共享城市或时区名称。

## 尚未完成（不能用于生产）

- 仍需在真实 Windows 机器上验证锁屏、安全桌面、前台进程读取、输入节奏和计时回绕，并补充 macOS 锁屏/解锁端到端测试。
- 浏览器内的视频或网页会议仍只能保守归为 `work`；除非未来由用户显式授权更强信号，否则不会读取标签页标题或 URL。
- 关系密钥仍由前端生成并保存在浏览器型本地存储中；未进 Keychain/Credential Manager，未实现 X3DH/Double Ratchet、撤销和多设备。

- 已有最小邮箱中继、短码配对和轮询收发，但没有推送、送达回执、密钥轮换、设备撤销、流量填充或独立安全审计。

- 缺少安装包签名、无障碍/权限 UX、安全审计、流量填充及完整可访问性。
- 更新功能目前完成版本源检查和新版本提醒；安装包签名发布后再接入安全的后台下载与原位安装。
